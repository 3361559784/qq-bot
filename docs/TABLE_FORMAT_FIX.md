# 📋 课程查询表格渲染问题 - 修复报告

## 🐛 问题描述

**用户反馈**：
> "现在是第几周？我想知道本周课程的顺序。"
> 
> Aris 的回复使用了**纯文本列表**而不是表格：
> ```
> 周一：08:00-08:45 大学英语（一）@E02-207，08:55-09:40 大学英语（一）@E02-207
> 周二：15:55-16:40 大学英语（一）@E02-207，16:50-17:35 大学英语（一）@E02-207
> ...
> ```
>

1. ❌ 没有自动切换到 Professional 模式（应该自动识别为课程查询）

## 🔧 技术细节

### 触发关键词（Class 模式）
```javascript
['课表', '课程表', '有课', '下一节课', '下节课', 
 '接下来有什么课', '明天有课吗', '今天有课吗', 
 '下周课表', '本周课表', '这周课表']
```

当检测到这些关键词时：
1. `inferredMode` 设为 `'Class'`
2. 自动推荐 `persona = 'professional'`
3. 应用 Class 模式的 `modeStyleOverride`（包含强制表格格式要求）

### Markdown 表格语法
```markdown
| 星期 | 时间 | 课程 | 地点 |
|:----:|------|------|------|
| 周一 | 08:00-09:40 | 高等数学 | E03-A101 |
```

生成的 HTML（前端渲染）：
```html
<table>
  <thead>
    <tr>
      <th style="text-align:center">星期</th>
      <th>时间</th>
      <th>课程</th>
      <th>地点</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td style="text-align:center">周一</td>
      <td>08:00-09:40</td>
      <td>高等数学</td>
      <td>E03-A101</td>
    </tr>
  </tbody>
</table>
```
