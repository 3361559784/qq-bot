# MVP评审反馈优化总结
## 📅 优化日期：2025-12-16

## 🎯 优化目标
根据 Imagine Cup MVP 评审反馈,对 Alice 校园助手进行专业性和边界处理优化,确保通过评审。

---

## 📋 MVP评审反馈的4个关键问题

### 1️⃣ 周次处理：需要逻辑推测而非简单道歉
**问题描述**：当课表没有周次信息时,Alice简单回答"我无法知道周次",显得不专业且缺乏解决方案。

**优化方案**：
- ❌ 错误："这门课是从第16周开始的"（编造数据）
- ❌ 不佳："我无法知道周次信息"（简单道歉）
- ✅ 正确：提供逻辑推测 + 3种解决方案
  1. 基于固定时间的课程安排（利用现有数据）
  2. 手动标注周次（引导用户补充信息）
  3. 未来优化方向（说明系统能力边界）

**实施位置**：`COPILOT_PROMPT_ZH` → `【🚨 数据边界严格约束】` 章节

---

### 2️⃣ 核心能力定位：过于分散,缺乏差异化
**问题描述**：当用户问"你和ChatGPT有什么区别"时,Alice列举通用能力（学习建议、心理支持等）,把自己拉回通用聊天机器人赛道。

**优化方案**：
**重新定位核心价值**：
- **产品名称**：Campus Copilot (校园副驾驶)
- **核心痛点解决能力**：
  1. 课程信息整合：快速查询课表、教室位置、课程时间
  2. 学习任务规划：基于课表自动生成学习计划、提醒作业和考试
  3. 校园生活效率提升：整合课程、活动、天气等碎片化信息

**与通用AI的本质区别**：
- 绑定用户的课表数据,只在授权数据范围内行动
- 理解校园时间节奏,不会编造不存在的课程或活动
- 提供可量化、可验证的校园信息服务

**标准回答模板**：
"如果没有您的课表数据,我只能进行非常有限的陪伴式对话;一旦您导入课表,我才能成为真正理解您校园生活节奏的 Campus Copilot。这就是我和通用聊天机器人的本质区别——我只在您授权的数据范围内行动,不会编造不存在的课程。"

**实施位置**：`COPILOT_PROMPT_ZH` → `【🔥 产品定位 - Campus Copilot 核心价值】` 章节

---

### 3️⃣ 缺少可演示场景：回答太概念化
**问题描述**：MVP评审需要看到具体可量化的场景,而非抽象的功能描述。

**优化方案**：
添加 **3个可演示场景模板**,每个场景包含：用户问题 + 标准回答示例

**场景1：课程查询**
```
用户："明天几点在哪上课？"
回答示例：
  "明天（周三）您有3门课程：
  - 08:00-09:40 机械工程制图 @教学楼A201
  - 10:25-12:00 高等数学 @教学楼B305  
  - 14:00-15:35 大学物理 @实验楼C102
  
  建议提前10分钟到达教室。"
```

**场景2：学习计划生成**
```
用户："这周有考试,帮我规划复习时间"
回答示例：(包含Markdown表格)
  | 日期 | 可用时间 | 建议复习科目 | 优先级 |
  |:----:|:----:|:----:|:----:|
  | 周二 | 14:00-17:00 | 高等数学（周四考试） | ⭐⭐⭐ |
  | 周四 | 09:00-12:00 | 大学物理（周五考试） | ⭐⭐ |
```

**场景3：边界处理示例**
```
用户："帮我安排健身时间"
回答："我只能基于课表帮您找出空闲时间段。根据课表,周三下午15:00后和周六全天无课,您可以自行安排活动。"
```

**实施位置**：`COPILOT_PROMPT_ZH` → `【🎯 可演示场景模板】` 章节

### 4️⃣ 语言风格：过度修饰降低专业性
**问题描述**：Chat模式中过多的emoji、感叹号、二次元口癖（"邦邦咔邦!!!"、"爱丽丝明白了!!!"）会让Alice显得不专业,像玩具而非工具。

**优化方案**：

#### 🔧 ARIS_PROMPT (Chat模式基础人设) 优化
1. **颜文字使用规则**：
   - ❌ 修改前："必须使用 ASCII 颜文字"
   - ✅ 修改后："建议控制频率（每条消息最多1-2个）"

2. **Few-Shot示例优化**：减少感叹号和夸张语气
   - ❌ 修改前："Sensei，早上好！(✨ω✨) 今天也有很多任务等待着我们呢！爱丽丝已经准备好出击了！"
   - ✅ 修改后："Sensei，早上好。今天也有很多任务等待着我们呢,爱丽丝已经准备好出击了。"

3. **添加核心指令第4条**：
   ```
   4. 校园场景优先（MVP核心定位）：
      - 当涉及课程、计划、学习任务时,优先使用 Campus Copilot 的专业能力
      - 突出你能整合课表、规划时间、提醒任务的核心价值
      - 不过度强调纯粹陪伴或情感支持功能
   ```

4. **添加限制与禁令**：
   ```
   - 专业性平衡（MVP要求）：保留个性化语言,但减少过度修饰（感叹号、颜文字过多会显得不专业）。
   ```

**实施位置**：`ARIS_PROMPT` lines 1542-1653
