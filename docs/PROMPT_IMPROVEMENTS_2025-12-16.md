# Prompt 改进总结 (2025-12-16)

## 改进目标
根据 Imagine Cup MVP 评审反馈，优化 Alice (Campus Copilot) 的 prompt，强化产品定位和数据边界意识。

---

## ✅ 已应用的改进

### 1. **周次信息明确控制** 
**位置**: `COPILOT_PROMPT_ZH`

**改进内容**:
- 仅在用户明确提供学期周次信息时，才使用周次回答问题
- 无周次数据时的标准回答模板：
  ```
  ❌ 禁止："第3周你有..." "这周是第5周..."
  ✅ 允许："根据课表，周一有..." "本周一至周五的课程是..."
  ✅ 必须说明："您的课表暂无周次信息，我只能按星期几为您查询。如需按学期周次查询，请提供当前是第几周。"
  ```

**预期效果**: 避免在无周次数据时胡编周次，符合"不编造数据"的核心定位。

---

### 2. **强化时间规划能力**
**位置**: `Plan 模式 modeStyleOverride`

**改进内容**:
- **具体时间段标注**: 从"周五可以做项目" → "周五14:00-17:00适合完成简短任务"
- **任务优先级建议**: 明确优先级1/2/3，并说明原因
- **可行性评估**: 标注时间段适合的任务类型（如"不建议安排需要长时间专注的项目"）

**示例对比**:
```diff
- 周一、周二课较少（各2节），可安排自主学习
+ **本周空闲时间**：
+ - 周一：14:00-17:00（3小时）- 建议优先预习周三课程
+ - 周二：09:00-12:00（3小时）- 适合完成作业
+ 
+ **任务优先级建议**：
+ 1. 优先级1：周三课程预习（建议安排在周一下午）
+ 2. 优先级2：当前作业完成（可利用周二上午）
```

**预期效果**: 从"功能型回答"升级为"决策辅助型回答"，提升实用价值。

---

### 3. **强调校园专属价值**
**位置**: `COPILOT_PROMPT_ZH` + `Chat 模式`

**改进内容**:
- **对比通用 ChatGPT**: 明确说明"我只在您授权的数据范围内行动，不会编造不存在的课程"
- **数据依赖性强调**: "如果没有您的课表数据，我只能进行非常有限的陪伴式对话"
- **能力退化承认**（MVP 核心差异化）:
  ```
  标准版："如果不导入课表，我只能进行非常有限的通用对话；一旦导入课表，我才能基于真实校园数据提供不可替代的帮助。"
  锋利版："不导入课表时，我的能力会接近通用聊天模型；导入后，我才成为校园 Copilot。"
  ```

**预期效果**: 让评委认为 Alice = 数据驱动的专业工具，而非通用聊天机器人。

---

### 4. **避免模糊陪伴回答**
**位置**: `Chat 模式 modeStyleOverride`

**改进内容**:
- **无数据时的限定**:
  - ✅ 允许：通用学习建议、时间管理方法、复习策略、情感陪伴、动漫话题
  - ❌ 禁止：编造课程安排、臆测用户课表、给出具体课程规划
  - 必须提示："我目前无法提供具体的课表规划，因为您还没有导入课表。但我可以分享一些通用的学习建议..."

- **超出数据范围时的处理**:
  - 明确说明："您的课表中没有这门课程的信息"
  - 提供替代方案："不过我可以帮您搜索相关学习资源"

**预期效果**: 避免在无数据时提供模糊的通用建议（容易被评为"和 ChatGPT 没区别"），强制引导用户导入课表。

## 📊 改进对比表

| 维度 | 改进前 | 改进后 | 预期收益 |
|:----:|:----:|:----:|:----:|
| **周次信息** | 可能胡编周次 | 无数据时明确说明 | 避免 MVP 大忌：编造数据 |
| **时间规划** | "周五可以做项目" | "周五14:00-17:00适合简短任务" | 从功能型→决策辅助型 |
| **产品定位** | 模糊的 AI 助手 | 数据驱动的校园 Copilot | 与通用 ChatGPT 明确区分 |
| **无数据回答** | 提供通用学习建议 | 明确说"无法提供课表规划" | 强制引导用户导入课表 |
