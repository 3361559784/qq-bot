# P0 功能测试用例
## 测试套件概览
本文件包含所有 P0 功能的完整测试用例，用于验证功能正确性。
---

## 🧪 测试类别 1: 回复优化与后处理

### 测试 1.1: Emoji 转颜文字
**前置条件:** `ARIS_EMOJI_CONVERT=true`

| 输入 | 预期输出包含 |
|------|------------|
| `@爱丽丝 今天好开心😊` | `(✨ω✨)` |
| `@爱丽丝 哈哈哈😃` | `(≧∇≦)/` |
| `@爱丽丝 好难过😢` | `( >﹏<。)` |
| `@爱丽丝 加油💪` | `(ง•̀ᴗ•́)ง✧` |

**验证方法:**
```bash
# 发送消息并检查回复
curl -X POST "https://your-function.azurewebsites.net/api/schoolBot" \
  -H "Content-Type: application/json" \
  -d '{
    "post_type": "message",
    "message_type": "group",
    "group_id": 123456789,
    "user_id": 123456789,
    "raw_message": "@爱丽丝 今天好开心😊"
  }'
```

### 测试 1.2: AI 腔修正
**输入:** `@爱丽丝 你能帮我吗？`

**不应包含:**
- "作为一个人工智能"
- "我可以为您"
- "让我来帮助您"

**应该包含:**
- "爱丽丝可以"
- "爱丽丝来帮忙"

### 测试 1.3: 回复长度控制
**配置:**
```env
ARIS_MIN_SENTENCES=3
ARIS_MAX_SENTENCES=4
ARIS_MIN_CHARS=120
ARIS_MAX_CHARS=150
```

**输入:** `@爱丽丝 给我讲个故事`

**验证:**
- 回复句数: 3-4 句
- 回复字数: 120-150 字范围内
- 没有被截断的半句话

### 测试 1.4: 智能分段
**配置:** `ARIS_SMART_SPLIT=true`

**输入:** `@爱丽丝 详细介绍一下你自己`

**预期:**
- 如果回复 >225 字，应分成多条消息
- 每条消息在句子边界切分
- 消息间有延迟（~800ms）

## 🧠 测试类别 3: 记忆系统

### 测试 3.1: 记忆存储
**前置条件:** 
- `ARIS_LONG_TERM_MEMORY=true`
- Cosmos DB 连接正常

**步骤:**
1. 发送: `@爱丽丝 我叫小明，今年18岁`
2. 等待 2 秒
3. 检查 Cosmos DB 是否有新记录

**验证 Cosmos DB:**
```sql
SELECT * FROM c WHERE c.userId = '123456789' AND c.type = 'conversation'
ORDER BY c.createdAt DESC
```

**预期字段:**
- `id`: `memory_123456789_*`
- `content`: 包含"小明"和"18岁"
- `vector`: 长度为 50 的数组
- `ttl`: 2592000 (30天)

### 测试 3.2: 记忆检索
**前置条件:** 已有记忆数据

**步骤:**
1. 存储: `@爱丽丝 我最喜欢蓝色`
2. 等待 5 秒
3. 查询: `@爱丽丝 你知道我喜欢什么颜色吗？`

**预期回复:**
- 提到"蓝色"
- 或者说"记得"/"知道"等关键词

### 测试 3.3: 相似度过滤
**配置:** `ARIS_SIMILARITY_THRESHOLD=0.7`

**步骤:**
1. 存储: `@爱丽丝 我家住在北京`
2. 查询: `@爱丽丝 天气怎么样？`（不相关查询）

**预期:**
- 不应检索到"北京"相关记忆
- 因为相似度 < 0.7

### 测试 3.4: Top-K 限制
**配置:** `ARIS_TOP_K_MEMORIES=3`

**前置:** 存储 5 条以上记忆

**步骤:**
1. 查询: `@爱丽丝 回顾一下我们的对话`

**验证日志:**
```
[记忆系统] 检索到 3 条相关记忆
```

### 测试 3.5: 记忆过期（TTL）
**配置:** `ARIS_MEMORY_DAYS=1` (仅用于测试)

**步骤:**
1. 存储一条记忆
2. 等待 25 小时
3. 查询 Cosmos DB

**预期:** 该记忆已被自动删除（TTL 机制）

## 📊 性能测试

### 测试 5.1: 响应时间
**目标:** 平均响应时间 < 2000ms

**步骤:**
```bash
# 发送 10 条消息并测量响应时间
for i in {1..10}; do
  time curl -X POST "https://your-function.azurewebsites.net/api/schoolBot" \
    -H "Content-Type: application/json" \
    -d "{...}"
done
```

**验收标准:**
- P50 < 1500ms
- P95 < 2500ms
- P99 < 3500ms

### 测试 5.2: 并发测试
**工具:** Apache Bench 或 wrk

```bash
# 10 个并发用户，100 个请求
ab -n 100 -c 10 -T 'application/json' -p test_payload.json \
  https://your-function.azurewebsites.net/api/schoolBot
```

**验收标准:**
- 错误率 < 1%
- 平均响应时间 < 2500ms

### 测试 5.3: 记忆系统性能
**场景:** 记忆数量增长到 1000+ 条

**步骤:**
1. 批量插入 1000 条记忆
2. 执行检索查询
3. 测量响应时间

**验收标准:**
- 检索时间 < 500ms (with indexes)
- 不影响整体响应时间

```sql
-- 查看最近记忆
SELECT TOP 10 * FROM c 
WHERE c.userId = '123456789' 
ORDER BY c.createdAt DESC

-- 统计记忆数量
SELECT COUNT(1) as count FROM c 
WHERE c.type = 'conversation'

-- 查找特定内容
SELECT * FROM c 
WHERE CONTAINS(c.content, '蓝色')
```
