# Alice / Campus Copilot

Campus AI-ассистент с безопасностью во главе угла, цель которого — **избежать галлюцинаций, дезинформации и смещения ответственности**.

> 💡 Если вы хотите понять, **почему существует этот проект**, и проследить путь дизайна, смотрите [DESIGN_PHILOSOPHY.md](DESIGN_PHILOSOPHY.md).  
> 🏗️ Для технической архитектуры и реализации системы — [ARCHITECTURE.md](ARCHITECTURE.md).

---

## Какую проблему решает проект?

Большинство кампусных чат-ботов оптимизируют:
- естественное общение
- сохранение персонажа
- метрики вовлечённости

Этот проект оптимизирует:
- ❗ **Отсутствие выдуманных расписаний** (никаких фальшивых времён занятий)
- ❗ **Чёткое распределение ответственности** (кто и за что отвечает)
- ❗ **Понимание, когда нужно отказаться**, и объяснение причин

---

## Основные принципы дизайна

| Принцип | Что значит |
|--------|-----------|
| **Evidence > Fluency** | Показываем источник данных, а не только гладкую речь |
| **Отказ должен быть объяснимым** | Любой «нет» сопровождается причиной |
| **Суждение за человеком** | ИИ помогает, человек принимает решение |
| **Эмоциональная зависимость не по умолчанию** | Приятное общение ≠ основная обязанность |

## Ключевые возможности

✅ **Многоуровневая маршрутизация безопасности**  
- детерминированные правила + проверки LLM + классификация намерений

✅ **Слой объяснимого отказа**  
- каждый отказ содержит: тег причины, альтернативную помощь, следующие шаги

✅ **Сначала уточнение контекста, затем поиск**  
- неясный ввод? Сначала спросим, затем решим, выполнять поиск или нет

✅ **Двойной режим взаимодействия**  
- QQ: персонаж Alice (живой, в духе кампусной культуры)  
- Web: режим Copilot (профессиональный, лаконичный)

✅ **Ручное подтверждение критичных действий**  
- нет автономных циклов; требуется одобрение человека

## Когда **не** использовать этот проект

❌ Нужно эмоциональное компаньон-ИИ  
❌ Нужны автономные агенты с самоперезапуском  
❌ «Человечность» важнее корректности  
❌ Требуется свободный чат без ограничений 24/7

## Быстрый старт

### Требования
- Node.js 20+
- Azure Functions Core Tools 4.x
- Подписка Azure (для Cosmos DB, Functions, AI Search)

### Локальная разработка

```bash
# 1. Установить зависимости
npm install

# 2. Настроить переменные окружения
cp local.settings.json.example local.settings.json
# Отредактируйте local.settings.json, добавьте свои ключи API

# 3. Запустить бэкенд (Azure Functions)
func host start

# 4. Запустить фронтенд (опционально, Web UI)
cd campus-ai-web && npm run dev
```

### Деплой в Azure

```bash
# Вариант 1: использовать скрипт
./deploy-functions.sh

# Вариант 2: пушить в ветку main (срабатывает GitHub Actions)
git push origin main
```
